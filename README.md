# 技術士第一次試験【19】環境部門 学習ツール

技術士第一次試験・専門科目（環境部門）の学習用Webアプリ。スマホのブラウザでそのまま使える。

**https://gijutsushi-quiz.pages.dev/**（Cloudflare Access で本人のみ）

> 移行中：現時点では https://yotsai.github.io/gijutsushi-quiz/ でも公開中。
> Cloudflare への移行が完了したらGitHub Pagesは停止し、リポジトリをprivateにする。

## 収録内容

### 1. クイズ 269問（環境部門・専門科目のみ）

| セット | 問数 | 内容 |
|---|---:|---|
| 白書・統計 | 68 | 環境白書・環境省統計の数値（4択） |
| 過去問論点 | 140 | 過去問で問われた論点の再構成（4択） |
| 測定・分析 | 30 | 最大ブロックの重点対策（4択） |
| 5択問題 | 31 | 既存学習アプリの46問を検証・統合（5択中心） |

適性科目・基礎科目は全部門共通で市販アプリが充実しているため、本ツールは**環境部門の専門科目に絞る**。
環境白書・環境省統計の論点68問と、過去問で実際に問われた論点を再構成した140問。すべてオリジナル作問で、過去問の問題文・選択肢は転載していない。
各問の正誤は日本技術士会の公開正答表と突き合わせて確定させている。
出題順は毎回シャッフルされる（同じ並びで覚えてしまうのを防ぐため）。選ぶと即座に正誤と解説が出る。**「← 前の問題」で戻れる**（解答済みなら選んだ選択肢と解説がそのまま復元される）。矢印キーでも移動可。最後に分野別の正答率と、間違えた問題だけの再挑戦。

**解答履歴（localStorage）**
- 各問の「これまで n回中 m回正解」を表示
- 直近で誤答した問題に「前回まちがえた」フラグ
- 出題範囲に「苦手」を追加（直近誤答 or 正答率6割未満を自動抽出）

**未検証問題の除外（既定ON）**

確度△（一次資料で未確認）の問題は**既定で出題されない**。検証済みの問題だけで学習できる。
チェックボックスで△を含めることも可能だが、その場合は警告を表示する。
実際にこれまでの検証で、既存データから5問の誤り（正答が逆・成立しない問題）が見つかっている。

**解説の確度表示**

各問の解説末尾に、どこまで裏を取ったかを明示している。

| 表示 | 意味 | 問数 |
|---|---|---|
| ◎ | 白書・法令・告示など一次資料で確認 | 110 |
| ○ | 公開正答表との突合により確定 | 159 |
| △ | 教科書的知識（一次資料は未確認・要確認） | 0 |

△は赤字で表示し、鵜呑みにしないよう促している。2026-09時点で△はゼロ（全問が◎か○）。

**中断と再開**
- 1問ごとに進捗（出題範囲・現在位置・正解数・解答内容）をlocalStorageへ自動保存
- 次に開くと続きから再開し、「前回の続き（23 / 102問目）から再開しました」と表示
- 「最初から解き直す」でリセット。完走すると保存は破棄される

**覚える理由（過去問の出題実績）**
- 各問に、過去7年（R1〜R7）で何回出た論点かを表示。頻出（出題年が2年以上）は解く前にラベル、解いた後に「★ 絶対に覚える理由」を出す
- 出題実績は、解説にある過去問番号と `topics.js` の頻出テーマから自動で付ける（問題ごとに理由を創作しない）。1回だけ出た問題はその番号を、実績のない問題は「確認できていない」と正直に表示
- 10問・20問で出題するときは、同じ条件なら出題実績のある問題から出す

**おまかせ出題（ホーム）**
- 問題ごとに次の復習日を管理する間隔反復。まちがえたら翌日、続けて正解するほど間隔を空ける（1→2→4→7→14→30日）
- 習熟度は5段階（未学習・要復習・学習中・定着・完璧）。要復習は直近誤答または正答率6割未満、定着は3回連続正解、完璧は5回連続正解
- 出題順は①復習日を過ぎた問題（古い順・習熟度の低い順）②まだ解いていない問題（頻出論点から）③期限前でも習熟度の低い問題、の順
- ホームの主役カードに今日の復習数をバッジ表示。出題数は5〜100問でスライダー調整

**スマホアプリ風のホーム**
- 下部ナビ（ホーム／頻出テーマ／履歴／印刷）で画面を切り替える、アプリのようなUI
- ホームはおまかせ出題の主役カード → 数字タイル（解いた問題・直近の正答率・苦手・ブックマーク）→ 分野タイル → 合格までの道のり、の順に並ぶ

**合格までの道のり（ホーム）**
- 本番までの残り日数と合格ライン（35問から25問を選んで13問正解）を常に表示
- 受験日はホームから変更でき（既定は2026/11/22）、この端末に保存。期日の目安（全問1周・正答率70%・測定分析50%未満なら頻出に絞る・苦手とブックマークだけの期間）はすべて受験日からの逆算で、変更すると自動で再計算される
- 「次にやること」を日付と進み具合から1つ選んでワンタップで出題。「★ 頻出論点だけ解く」はいつでも押せる
- 解きかけの回がないときは起動するとホームから始まる（解きかけがあれば続きから）

**ブックマークとメモ**
- 各問の右上「☆ ブックマーク」「メモ」から保存（localStorage・自動保存）
- 出題範囲に「★ ブックマーク」を追加。ブックマークした問題だけを解ける
- メモは解答前は閉じておき、解答後に解説の下で開く（答えを書いたメモが先に見えないように）

**履歴タブ**
- 全問の正誤履歴を一覧（間違えた問題／すべて／未回答／ブックマーク／メモありで絞り込み、正答率の低い順）
- 絞り込んだ問題だけをその場で出題
- 学習データ（解答履歴・ブックマーク・メモ）をJSONで書き出し／読み込み。機種変更やURL移行（GitHub Pages→Cloudflare）の前に使う。同じ問題は解答回数の多い方・新しいメモの方を残すので、同じファイルを2回読んでも回数は増えない

**学習診断**
- 分野別の正答率 ×（本試験での年間出題数）＝ **▲落とす問題数の見込み**
- 出題が多い分野ほど同じ正答率でも損失が大きくなるため、優先順位が数字で出る
- 「診断結果をコピー」でテキスト化。Claudeに貼れば次にやるべきことを分析できる

誤答選択肢は本試験の引っかけパターンに寄せてある。

- 桁違い（一般廃棄物3,811万t ↔ 産業廃棄物3億6,725万t）
- 目標値と実績値の混同（2013年度比の実績28.7% ↔ 2030年度目標46%）
- 大小関係の逆転（一般廃棄物の残余年数24.9年 ↔ 産業廃棄物の20.3年）
- 入口側19% ↔ 出口側44%（分母が違う最頻出論点）

### 3. 過去問の頻出テーマ
令和元年度（再試験）〜令和7年度の専門科目 245問（35問×7年）を1問ずつ分類した結果。

| 分野 | 7年計 | 比率 |
|---|---|---|
| 環境測定・分析 | 81 | 33% |
| 自然環境・生態系 | 51 | 21% |
| 法令・制度 | 42 | 17% |
| 地球環境・政策 | 23 | 9% |
| 白書・環境省統計 | 28 | 11% |
| 国際条約・国際報告書 | 13 | 5% |
| 計算問題 | 7 | 3% |

7年で2回以上出たテーマは48件、3回以上は28件。★印の3件は**選択肢まで同一で再出題**されており、
順序が入れ替わるだけであることを正答表との突き合わせで確認済み。各問の「覚える理由」はこの7年分の出題実績から自動で付く。

## 著作権について

**過去問の問題文・選択肢は転載していない。** 掲載しているのは分類結果と論点の要約のみで、
問題番号は[日本技術士会の公開過去問](https://www.engineer.or.jp/c_categories/index02021.html)への参照。
実物はそちらを参照すること。

クイズはすべてオリジナル作問。

