# 技術士第一次試験【19】環境部門 学習ツール

技術士第一次試験・専門科目（環境部門）の学習用Webアプリ。スマホのブラウザでそのまま使える。

**https://yotsai.github.io/gijutsushi-quiz/**

## 収録内容

### 1. 数値クイズ 44問
環境白書・環境省統計から実際に出題されている論点を4択にしたもの。すべてオリジナル作問。
選ぶと即座に正誤と解説が出る。最後に分野別の正答率と、間違えた問題だけの再挑戦。

誤答選択肢は本試験の引っかけパターンに寄せてある。

- 桁違い（一般廃棄物3,811万t ↔ 産業廃棄物3億6,725万t）
- 目標値と実績値の混同（2013年度比の実績28.7% ↔ 2030年度目標46%）
- 大小関係の逆転（一般廃棄物の残余年数24.9年 ↔ 産業廃棄物の20.3年）
- 入口側19% ↔ 出口側44%（分母が違う最頻出論点）

### 2. 過去問の頻出テーマ
令和4〜7年度の専門科目 140問（35問×4年）を1問ずつ分類した結果。

| 分野 | 4年計 | 比率 |
|---|---|---|
| 環境測定・分析 | 46 | 33% |
| 自然環境・生態系 | 28 | 20% |
| 法令・制度 | 24 | 17% |
| 地球環境・政策 | 16 | 11% |
| 白書・環境省統計 | 16 | 11% |
| 国際条約・国際報告書 | 7 | 5% |
| 計算問題 | 3 | 2% |

「4年で2回以上出たテーマ」を回数順に掲載。うち3件は**選択肢まで同一で再出題**されており、
順序が入れ替わるだけであることを正答表との突き合わせで確認済み。

## 著作権について

**過去問の問題文・選択肢は転載していない。** 掲載しているのは分類結果と論点の要約のみで、
問題番号は[日本技術士会の公開過去問](https://www.engineer.or.jp/c_categories/index02021.html)への参照。
実物はそちらを参照すること。

数値クイズ44問はすべてオリジナル作問。

## ファイル構成

```
index.html    アプリ本体（UI・クイズロジック）
data.js       数値クイズ44問
topics.js     分野別集計と頻出テーマ
answers.json  令和4〜7年度 環境部門の正答140問（公開正答表から機械抽出）
```
