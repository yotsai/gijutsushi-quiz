# 技術士第一次試験【19】環境部門 学習ツール

技術士第一次試験・専門科目（環境部門）の学習用Webアプリ。スマホのブラウザでそのまま使える。

**https://yotsai.github.io/gijutsushi-quiz/**

## 収録内容

### 1. クイズ 72問（白書・統計44問／過去問論点28問）
環境白書・環境省統計の論点44問と、過去問で実際に問われた論点を再構成した26問。すべてオリジナル作問で、過去問の問題文・選択肢は転載していない。
各問の正誤は日本技術士会の公開正答表と突き合わせて確定させている。
選ぶと即座に正誤と解説が出る。最後に分野別の正答率と、間違えた問題だけの再挑戦。

**解答履歴（localStorage）**
- 各問の「これまで n回中 m回正解」を表示
- 直近で誤答した問題に「前回まちがえた」フラグ
- 出題範囲に「苦手」を追加（直近誤答 or 正答率6割未満を自動抽出）
- 結果画面に累計解答数・累計正答率・履歴リセット

誤答選択肢は本試験の引っかけパターンに寄せてある。

- 桁違い（一般廃棄物3,811万t ↔ 産業廃棄物3億6,725万t）
- 目標値と実績値の混同（2013年度比の実績28.7% ↔ 2030年度目標46%）
- 大小関係の逆転（一般廃棄物の残余年数24.9年 ↔ 産業廃棄物の20.3年）
- 入口側19% ↔ 出口側44%（分母が違う最頻出論点）

### 2. 印刷用シート（A4・4ページ）

**[print.html](https://yotsai.github.io/gijutsushi-quiz/print.html)** — ブラウザから直接印刷できる書き込み式シート。
PDF版も同梱：**[kankyo-anki-sheet.pdf](https://yotsai.github.io/gijutsushi-quiz/kankyo-anki-sheet.pdf)**

### 3. 過去問の頻出テーマ
令和4〜7年度の専門科目 140問（35問×4年）を1問ずつ分類した結果。

| 分野 | 4年計 | 比率 |
|---|---|---|
| 環境測定・分析 | 46 | 33% |
| 自然環境・生態系 | 28 | 20% |
| 法令・制度 | 24 | 17% |
| 地球環境・政策 | 16 | 11% |
| 白書・環境省統計 | 16 | 11% |
| 国際条約・国際報告書 | 7 | 5% |
| 計算問題 | 3 | 2% |

「4年で2回以上出たテーマ」を回数順に掲載。うち3件は**選択肢まで同一で再出題**されており、
順序が入れ替わるだけであることを正答表との突き合わせで確認済み。

## 著作権について

**過去問の問題文・選択肢は転載していない。** 掲載しているのは分類結果と論点の要約のみで、
問題番号は[日本技術士会の公開過去問](https://www.engineer.or.jp/c_categories/index02021.html)への参照。
実物はそちらを参照すること。

数値クイズ44問はすべてオリジナル作問。

## ファイル構成

```
index.html    アプリ本体（UI・クイズロジック）
print.html    印刷用シート（A4・4ページ）
kankyo-anki-sheet.pdf  同PDF版
data.js       白書・統計クイズ44問
pastq.js      過去問論点クイズ28問
topics.js     分野別集計と頻出テーマ
answers.json  令和4〜7年度 環境部門の正答140問（公開正答表から機械抽出）
```
